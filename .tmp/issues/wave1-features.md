## Contexto

Seção de features mostra os principais benefícios do produto. Precisa ser visual e fácil de escanear.

## Critérios de Aceite

- [ ] Grid de 6 features principais
- [ ] Cada feature: ícone Lucide + título + descrição curta
- [ ] Features: Webinários ao vivo, Just-in-Time, Chat ao vivo, CTAs inteligentes, Analytics, Multi-tenant
- [ ] Layout: 3 colunas desktop, 2 tablet, 1 mobile
- [ ] Hover state nos cards
- [ ] Título da seção: "Tudo que você precisa para converter"

## Dependências

Nenhuma (Wave 1)
