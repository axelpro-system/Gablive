# Gablive — assets oficiais

Kit de marca baseado no manual do Sistema Gablive e nos tokens reais do produto.

## Arquivos

- `logo.svg`: lockup oficial para fundos claros.
- `logo-dark.svg`: lockup oficial para fundos escuros.
- `logo-mark.svg`: símbolo para navegação, avatar e áreas compactas.
- `favicon.svg`: versão reduzida para navegador.
- `brand-tokens.css`: tokens de cor da identidade.

## Conceito

O símbolo combina uma timeline, uma curva de comportamento e um ponto exato de conversão. `Gab` usa o neutro principal e `live` usa o vermelho de marca. A composição evita aparência de videoconferência e reforça infraestrutura de conversão, precisão e controle.
